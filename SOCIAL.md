SCR Saver 0.1.12-alpha

https://github.com/robotkinz/SCR-Saver

What's new:

- Per-prefix Scaling for 640×480 savers such as 3D Maze: Off, Fit (4:3 with bars), Stretch, or Widescreen
- Mode-switching savers stay on their own screen
- Troubleshooting: optional real-time debug log with a live log window
- Escape and mouse movement now stop savers with a looping autoplay macro
- Dismissing a saver clears the screen at once; cleanup runs in the background
- An unreadable config file is kept as `config.json.bad-*` instead of being overwritten
- Stopping a saver no longer closes a file manager open in its Wine prefix folder
